# 萌百问答

群里有人问「你认不认识 XXX」「你知不知道 XXX 是什么」，机器人去萌娘百科查一条，用自己的口吻回一句，末尾附上条目链接。

答案不是凭空编的：先把萌百条目开头的纯文本抓回来，再让模型压成一两句人话。**查不到就不吭声**，不抢正常聊天的话。

## 安装

**方式一（推荐）**：到 [Releases](https://github.com/dermcji/astrbot_plugin_moe_wiki/releases/latest) 下载 `astrbot_plugin_moe_wiki-v1.0.1.zip`，解压后把 `astrbot_plugin_moe_wiki` 文件夹放进 AstrBot 的 `data/plugins/`，重启或在插件管理页点重载。

**方式二**：在 AstrBot 插件市场的仓库地址里填 `https://github.com/dermcji/astrbot_plugin_moe_wiki`。

装完在插件配置页能看到下面这些开关，不用改源码。

## 配置

| 配置项 | 默认 | 说明 |
|---|---|---|
| `moe_enabled` | 开 | 总开关，关掉后连 `/萌百` 命令也不响应 |
| `moe_allowed_qq` | 空 | 只有这些 QQ 号能触发。留空 = 谁都能用；填了就只认列表里的人 |
| `moe_allowed_groups` | 空 | 只有这些群能触发。留空 = 所有群；填了就只在列表里的群生效，私聊不受限 |
| `moe_auto_detect` | 开 | 自动识别问句；关掉后只能用 `/萌百` 手动查 |
| `moe_require_at` | 关 | 开着时只有 @ 机器人或唤醒词开头才自动查，群里闲聊问到什么都不理 |
| `moe_use_llm` | 开 | 用模型压成一句人话；关掉就直接截取条目原文 |
| `moe_max_chars` | 160 | 回答字数上限（40~600） |
| `moe_with_link` | 开 | 回答末尾附萌百条目链接 |

**白名单怎么理解**：`moe_allowed_qq` 和 `moe_allowed_groups` 两个都空 = 不设防，谁都能用；只要填了其中一个，就按填的那个卡——人不在列表里、或者群不在列表里，都不会去查。

## 用法

自动触发，直接问就行：

```
群友：你认不认识初音未来
bot：【初音未来】初音未来是由 Crypton Future Media 企划开发的语音合成软件……
     https://zh.moegirl.org.cn/初音未来
```

```
群友：原神是什么
bot：【原神】《原神》是米哈游研发的一款开放世界冒险游戏……
```

也支持手动查：

| 指令 | 作用 |
|---|---|
| `/萌百 初音未来` | 明确查一个词条，查不到会告诉你没找到 |
| `/萌百状态` | 看当前开关、白名单、字数上限 |

能识别的句式包括「你认不认识 X」「你知不知道 X 是什么」「你知道 X 吗」「你了解 X 吗」「你听过 X 吗」「X 是什么」「X 是谁」。

不像词条的会直接放过，比如「你知道我在想什么吗」「今天几号」——不查、不回，交给主流程正常聊天。

## 原理

1. 正则从消息里抠出词条名，过滤掉代词和疑问残渣；
2. 打 [`zh.moegirl.org.cn`](https://zh.moegirl.org.cn) 的 MediaWiki API：`action=query&prop=extracts&exintro` 取条目开头；
3. 原词查不到时用 `action=opensearch` 找最接近的标题再试；
4. 命中消歧义页（`pageprops.disambiguation`）时，把该页的分支条目（如 `白花` → `白花(保健室的老师系列)`、`白花(铃木木乃美)`）连同各自引言一起交给模型挑；
5. 有可用模型就按**当前会话人设**压成一两句话，没有就直接截取原文；
6. 结果缓存 30 分钟，同一会话 20 秒内不重复答同一个词。

请求带 UA、有间隔限流，不给萌百服务器添乱。
